In order to avoid hallucinated references in Geomatics theses, I've implemented a reference checking system. This will be used for the upcoming A3 period.

Supervisors will be getting a report of all references and whether they're confirmed, suspicious or (most likely) hallucinated.

So, especially if you're using an LLM, make sure you have verified all of your references before sending the report to your supervisors.
